WIZARD ACADEMY · VERSION 1.5.0

Your institution begins here.

The game has no build step. Upload the files, configure Firebase once, and open your GitHub Pages address.

Publish from a phone or iPad

  1. Unzip the download and put every file directly in your GitHub repository root. Do not put the files in a folder inside your repository.
  2. In GitHub Settings → Pages, publish your branch from / (root).
  3. Open Firebase Console and select wizardacademy-ef68b.
  4. Enable Authentication → Email/Password.
  5. Create the default Cloud Firestore database if necessary. Paste firestore.rules into its Rules tab and publish.
  6. Add your GitHub Pages hostname to Authentication → Settings → Authorized domains.
  7. Open your GitHub Pages game address. Create an account, name the academy, open its doors, and recruit your first five wizards.
Want to play before configuring Firebase?
Choose “Play locally on this device.” That academy stays in your browser. Use Front Desk → Settings & save to export backups. Local and cloud academies are separate.

Read before descending

Every new floor stops for your decision. Bosses cost a seal, even on the first attempt. Fallen wizards die permanently. Their equipment can be recovered. Magic Missile needs no equipment or runes.

Open the Practice Hall, Rune Chamber, and Arcane Rift. Keep five eligible starters configured for matches. Assign producers to make blank runes and inscribers to turn them into spell charges.
